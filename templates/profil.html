Alur Penggunaan (User Flow)
  1. Admin membuka Dashboard untuk melihat ringkasan stok dan peringatan restok.
  2. Admin membuka Daftar Barang, lalu mencari atau mengurutkan data.
  3. Barang baru dicatat lewat Tambah Barang, atau data lama diubah lewat tombol Edit.
  4. Barang yang sudah tidak dijual dihapus lewat tombol Hapus dan konfirmasi di modal.
  5. Kembali ke Dashboard untuk memastikan angka ringkasan sudah diperbarui.
