# InvenTrack

Sistem Informasi Manajemen Inventaris Toko Alat Tulis.

InvenTrack membantu pemilik toko mencatat dan memantau stok barang dalam satu aplikasi desktop yang mudah dipakai.

## Fitur

- Dashboard ringkasan berisi jumlah jenis barang, total stok, nilai inventori, dan grafik stok per kategori
- Notifikasi otomatis saat stok menipis
- Kelola data barang berisi lihat, cari, tambah, edit, dan hapus
- Validasi isian form agar data tetap rapi
- Halaman profil kelompok

## Cara Menggunakan

1. Buka file `InvenTrack.exe`.
2. Tunggu jendela aplikasi muncul.
3. Gunakan menu di sebelah kiri untuk berpindah halaman.

Tidak perlu instalasi tambahan.

## Catatan

- Ini adalah prototipe, sehingga data barang yang diubah tidak tersimpan setelah aplikasi ditutup.
- Aplikasi berjalan di Windows 10/11.
